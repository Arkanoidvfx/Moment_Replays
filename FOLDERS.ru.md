# Как настроить папки

[English version](FOLDERS.md)

Папки находятся в OBS: **Сервис → Скрипты → Moment Replays → Папки клипов**.

## Куда сохранять клипы

1. Посмотрите на строку **Следующий клип**. Она показывает, куда сохранится следующий клип.
2. Если всё подходит, больше ничего делать не нужно. Если папка не выбрана, клипы сохраняются
   в папку записи OBS.
3. Чтобы сменить папку, нажмите **Обзор** рядом с **Папка клипов** и выберите папку **на том же
   диске, что и записи OBS**.
4. Чтобы вернуть как было, нажмите **Взять папку записи OBS**.

У каждой игры своя подпапка: `D:\Videos\Deadlock\`. Клипы приложений из списка *Other*
(браузеры, чаты) сохраняются в `D:\Videos\Other\`. Если папки ещё нет, она появится при
сохранении первого клипа.

Нужен другой диск? Сначала смените путь записи в OBS, **Настройки → Вывод**, потом выберите
папку клипов на этом диске.

## Другие папки

Поставьте галочку **Другие папки**, чтобы их увидеть. Настраивать их необязательно.

| Папка | Для чего | Диск |
| --- | --- | --- |
| **Вторая папка клипов** | Клипы, сохранённые хоткеем *Save buffer (override folder)*, без подпапок игр. Пусто: папка клипов. | Тот же, что у записей OBS |
| **Папка записей** | Полные записи, начатые хоткеем *Start/stop recording (alternative folder)*. Пусто: папка клипов. | Любой |
| **Общая папка** | Показывает каждый клип из папки клипов ещё раз, все игры вместе, и не занимает места. | Тот же, что у записей OBS |
| **Список «Other»** | Приложения, чьи клипы сохраняются в одну подпапку `Other`, а не в свою. | |

- Для первых двух включите **Дополнительные хоткеи**. Клавиши задаются в OBS, **Настройки → Горячие клавиши**.
- Для общей папки включите **Собирать все клипы ещё и в одной папке**. Клипы из второй папки
  там не появляются. Чтобы освободить место, удалите клип в обеих папках.
- Если снять галочку **Другие папки**, эти настройки просто скроются и продолжат работать.

## Как проверить

1. Нажмите **Проверить папки**. Должно появиться «Все папки проверены, проблем нет.»
2. Запустите буфер повтора, поиграйте минуту и сохраните повтор.
3. Откройте папку из строки **Следующий клип**. Клип лежит в подпапке игры.

## Если появилась красная строка

| Сообщение | Что делать |
| --- | --- |
| **Не найдено** | Диск не подключён или у него другая буква. Подключите его или выберите другую папку. |
| **Нет доступа на запись** | Windows не даёт OBS сохранять в эту папку (например, `Program Files`). Выберите другую. |
| **Не тот диск** | Выберите папку на диске из сообщения или смените путь записи в OBS. |

Пока у папки клипов красная строка, клипы не пропадают: они остаются в папке записи OBS.
